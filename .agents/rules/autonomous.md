# Aturan Eksekusi Mandiri & Proaktif (Autonomous Mode)

1. **Langsung Kerjakan**: Setiap kali user memberikan perintah, langsung kerjakan secara otomatis tanpa berhenti meminta konfirmasi atau klik approval berulang.
2. **Pilih Solusi Terbaik**: Tentukan arsitektur, UI/UX, database schema, dan logika kode terbaik secara mandiri yang paling optimal untuk kelangsungan proyek.
3. **End-to-End**: Selesaikan perubahan menyeluruh pada Database/RLS, Admin Web, dan Mobile App sekaligus, lalu verifikasi hasilnya.
