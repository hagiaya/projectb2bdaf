# Aturan Eksekusi Expo & Mobile App

- **DILARANG** menjalankan Expo dengan flag `--web` (misal: `npx expo start --web` atau `npm run web`). Menjalankan Expo dalam mode web sangat membebani resource CPU dan RAM (berat).
- **SELALU** jalankan Expo secara standar menggunakan:
  ```bash
  npx expo start
  ```
  atau
  ```bash
  npm start
  ```
- Aturan ini berlaku untuk semua project di workspace ini.
